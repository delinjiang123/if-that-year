# 如果那年 · 独立评价备忘

> 评价时点：v0.16.1（主线最新提交 17657ef，2026-11-01）
> 评价对象：`delinjiang123/if-that-year`（`Toygaolingxiao/if-that-year` 的 fork，评价时两者最新提交一致，尚未分叉）
> 评价方法：通读 README、方案设计书（前半部分）、增长文档、竞品报告、独立评审与三方审稿、扩容文档，以及仓库结构与事件包规模。**不是真机全程试玩，也不是上线后的用户数据评审**——因为站点尚未上线、匿名埋点默认关闭，所有关于完局率、分享率、付费的数据都还不存在。本评价的上限是“设计与代码评审”，下限结论必须等上线数据来推翻或证实。
> 立场：完全从独立第三方角度写，不沿用项目内部“已定结论”当证据。内部文档的说法只当作“项目方的说法”，有代码或模拟数字支撑的才算证据，没有的都标为待验证。

## 一句话结论

**题眼是真的，机制是真的，工程底子比同类小游戏扎实；但它现在还只是一个“做得很好的未上线产品”，不是一个“已被验证会裂变、会赚钱的产品”。**

值得继续做，不值得现在就按爆款或大规模变现去投入。正确的顺序仍然是：先上线、先测完局率 / 分享率 / 首笔付费这三个数，数不过线就收窄或转 B 端工具，不要用加内容来掩盖验证缺失。

## 一、立意：9 / 10 的题眼，7 / 10 的表达锋利度

### 好在哪里

- 题眼抓的是普遍心理，不是小众趣味。几乎每个人都想过“如果那年我选了另一条”。反事实思考、可能的自我、安全彩排，这三条心理机制是真实且跨年龄的，25–45 岁的主力人群尤其容易代入。
- 差异化不在题材，在机制。市场上已经有“随机投胎抽卡”和“重开刷稀有结局”两个位置，本项目占的第三个位置是**选择 + 影子人生**：未选之路不消失，在 30 / 40 / 50 岁可以瞥见，结算时揭晓代价。这个机制本身就是一句可以传播的话，也是别人抄走需要整套状态设计才能抄走的东西。
- 伦理克制是立意的一部分，不是装饰。结局不分贵贱、不卖改命与好结局、不搞财富排名、不做打卡焦虑、不把苦难做成笑点。这些克制在短期会损失转化，在长期是口碑、B 端采购和媒体转发的护栏。一个讲“人生没有标准答案”的产品，如果自己先给玩家打分，立意就塌了。

### 弱在哪里

- 钩子需要解释，不够锋利。竞品报告已经点破了：“选一条走到底，也看没选的那条”需要两句话才能讲清，而“重开一次”“80 亿分之一”一句话就够了。首屏如果不能在 3 秒内让人明白“我要点什么、会得到什么”，题眼再好也会在入口流失。
- 温暖克制的另一面是情绪密度偏平。三方审稿抽样里，平淡日常占 47%，幽默只有 9%，沉重 7%。这不是文笔差，而是产品主动放弃了梗、爽点和稀有收集这些最容易制造截图冲动的手段。立意高，不等于每一局都有让人想转发的瞬间。
- 人群画像偏“城市工资收入者的一生”。三方审稿指出：城市标记远多于县城、农村，伴侣线、有孩线供给远厚于单身线、无孩线，结构性变量（户籍、计生、房改、下岗等）多在年代包里做布景，通用池里退场。立意说“任何活法都体面”，供给如果做不到，立意就会被玩家在第二局、第三局里证伪。

**独立判断：立意是这个项目最值钱的部分，也是最不能被“优化”掉的部分。改钩子、改节奏都可以，但不要为了短期转化改成成功学模拟器或搞笑重开器，那等于把护城河拆了换流量。**

## 二、游戏性：更像“可交互的人生小说”，不是“策略游戏”

### 实际玩法（按 v0.16.1 的 README 归纳）

- 5 条开局路线，4 档出生年代（1955 / 1965 / 1978 / 2000），终点由活法决定（死亡或活到 80 岁）。
- 8 个大分岔（25 / 28 / 31 / 33 / 38 / 44 / 52 / 58 岁），每个 3 个选项，选择写标记，后文事件按标记回响；另有 1 个条件分岔。
- 六维数值（健康 / 金钱 / 成长 / 自由 / 关系 / 智慧），只影响事件概率与结局文案，不做胜负判定。
- 2102 条可抽事件（核心 45 + 内容包 2049 + 多前置组合事件 8），另有稀有事件 31 条、特殊结局 17 个；项目自报 16000 局模拟：任一特殊结局命中约 12%，两局事件重合率约 6.1%，判词精确碰撞率 1.43%。
- 影子瞥视在 30 / 40 / 50 岁；开局抽牌（三类牌各 3 选 1）、本地“活过的人生”记录、每日种子、自动推进三态、结算纵轴分岔图、分享台（判词卡 / 流水账卡 × 4:5 / 9:16）。

### 优点

1. **决策有回响，这是从 v0.1 评审后最关键的进步。** 早期评审曾直言“选择不设状态、不影响抽池”是假的；现在分岔写标记、事件带 require / forbid / route 条件、状态矩阵用注册表管流转、去世类状态没有出边，入库前跑 `tools/validate-state.js`。这套纪律让“选了独身，后面不再冒出‘你们’”这类穿帮在机制上更难发生。
2. **内容量过了“第二局不重复”的门槛（按项目模拟数字）。** 如果 6.1% 的重合率和 1.43% 的判词碰撞率属实，第二局的新鲜感是够的。内容量本身不是护城河，但低于门槛一定会死，高于门槛才能谈别的。
3. **确定性种子引擎是游戏性的地基。** 同一种子可复现，支撑同种子对战、每日种子、分享回流；在线零 LLM 调用，意味着对局成本、语气漂移、前后矛盾三类风险都被架构堵死了。
4. **自动推进和速度档是懂手机用户的设计。** 平年自动走、分岔 / 危机 / 稀有 / 瞥视必停、按文字长度算停留、默认全程自动推进，这些都是在解决“人生局太长、文字太多”这个真实矛盾。

### 缺点

1. **决策密度低。** 真正的大分岔只有 8 个，摊到 22–80 岁的一局里，大量年份是年度小事件或自动推进。玩家大部分时间在“读”，不是在“玩”。这对喜欢叙事的玩家是优点，对期待策略、养成、收集的玩家是短板——而后者恰恰是复玩和付费意愿更强的群体。
2. **数值没有“牙齿”。** 六维只影响概率与文案，不做胜负、不做 build、不做长期目标。玩家没有“我要把某条线练出来”的抓手，一局结束后的再开动力主要靠“还没见过的事件 / 结局”，而不是“我要打通某个玩法”。
3. **影子人生仍是查表文本，不是完整推演。** README 的“未实现”清单里写得很清楚：影子完整推演引擎还没做，现在是查表文本。核心卖点在体验层面是“剪影 + 代价句”，不是“另一条人生真的被完整模拟了一遍”。对外口径如果说成后者，资深玩家和媒体一深挖就会觉得被夸大。
4. **时长与碎片时间的矛盾没有彻底解决。** 设计书说轻局 6–8 分钟、完整局 18–25 分钟，但 v0.16 的 README 又说“无结束年龄设置，终点由活法决定（死亡或活到 80 岁）”。轻局到底是不是一个独立模式、玩家能不能在 10 分钟内完整体验一次“选 + 影子 + 结算”，从文档里看不清楚。竞品报告还提到首屏脚本约 968KB（事件包合计约 891KB，未计引擎与样式），按年代懒加载还是建议状态——手机弱网下的首屏体验仍是待验证项。
5. **历史偏斜是否根治，没有同口径复测。** 三方审稿（v0.11 时点）指出的问题很具体：关系登顶 77.4%、金钱垫底 90.0%、配偶悬空局 27%、孩子悬空 7.9%、年代错位约 82–94 条、父亲“复活”条件复活率约 18%。v0.12–v0.16 修了状态矩阵和门控，但项目里没有一份用同样口径重跑的复测报告。不能默认“修了机制 = 修了供给”，必须重跑一次分布审计才能下结论。

**独立判断：游戏性够“好读、好想、好分享”，不够“好玩、好练、好追”。这不是缺点清单里的某一项，而是品类选择：它注定是一个情绪叙事产品，不是系统驱动的游戏。接受这个定位，就不要用游戏的留存指标去苛求它；但也不要假装它有游戏的留存能力。**

## 三、裂变性：机制设计是 8 分，闭环落地是 5 分，实测是 0 分

### 机制上确实有裂变基因

- **结算卡是社交货币的正确形态。** 判词一句 + 关键分岔一句 + 影子一行 + 六维形状 + 同局链接，五要素齐了。尤其是影子一行（“另一条路上的你：县城中学老师，两个孩子，周末钓鱼”），是别人没有的好奇心入口。
- **同种子对战是可比性引擎。** 同样的运气、不同的选择，天然产生讨论；链接带 seed + era + cards（出身牌），回流的人玩的是同一道题，不是随机一局。
- **定向挑战比广播分享强。** “我这局没敢回老家，你来试试选回去会怎样”是一对一的社交动作，转化逻辑上高于“大家快来玩”。
- **每日种子是低成本的回访钩子。** 人人同日同题，适合做“今天这道题”的话题，不需要后端和账号。

### 闭环上还有断点（按项目自己的增长文档核对）

增长文档（2026-10-31 状态更新）承认未落地的 P0 / P1 项包括：挑战落地横幅与挑战摘要参数、卡面钩子 A/B 分组、同局对照块与对照卡、匿名埋点、精选故事墙、今日种子本地三件套（连续天数、昨日判词回看、明日预告）。README v0.15–v0.16 说部分留存记录（streak、lastlife、每日种子）已落地，但挑战横幅、对照卡、A/B 分组在 README 里没有明确的“已落地”表述——**在没有逐项核对代码之前，应按“未完全闭环”来评估。**

这意味着现在的裂变链是：能生成卡、能复制链接、朋友能用同一种子开局；但朋友落地时不知道“谁让我玩、他活成了什么样”，完局后也不会自动生成两人对照卡，第二轮传播要靠手动。链路每断一处，K 值就掉一截。

### 实测是 0 分——这是最重要的一句

- 站点尚未上线（Cloudflare Pages 接入尚待在后台完成）。
- 匿名埋点已备接口但默认关闭，收集端随接入时才开启。
- 因此完局率、分享率、同局链接开局率、K 值、次日回访，**目前全部没有真实数据**。增长文档里列的健康线（完局 ≥55%、分享 ≥15%、每千名玩家有效分享卡 ≥120、同局开局率 ≥35%、K ≥0.2）是目标，不是成绩。
- 设计书自己也算清了：广播分享在绝大多数情景下系数 <1。也就是说，即使机制再好，也不能默认它会自传播；必须靠定向挑战和同种子对战这两条更窄、更具体的链路去验证。

**独立判断：裂变性是“设计上最有希望、证据上最薄弱”的一项。给它打高分是讲故事，给它打低分是不公平——正确的打法是：上线后 4 周内只看三个数（完局率、分享率、同局开局率），任何一个长期低于增长文档的警戒线，都应先修链路断点，而不是加新功能或买量。**

## 四、未来价值：文化价值高，商业天花板中等，IP 延展有条件

### 价值从哪里来

1. **机制资产。** “选择 + 影子人生”如果能在中文市场先占住心智，就是品类位置资产。后来者即使抄机制，也抄不走已经积累的事件库、状态矩阵和玩家故事。
2. **内容资产。** 2150 个 ID、2049 条内容包事件、56 张出身牌、1080 种判词组合（按项目口径），这是一座需要人工审核才能建起来的库。它的价值不在于条数，而在于门控、年代、价值观三道关都过了的条数——而这三道关的通过率，恰恰是现在最需要复测的部分。
3. **信任资产。** 免注册、本地存档、隐私最小化、数据有出处才写数字、敏感话题有协议，这些在 B 端（学校、咨询、企业关怀）和媒体那里是加分项，在 C 端是“这个产品不贩卖焦虑”的口碑。
4. **延展资产。** 判词、影子、每日种子、故事墙，天然可以延展到播客、出版、展览、生涯课程。但延展的前提是先有真实玩家故事资产——故事墙现在还是计划，不是资产。

### 价值的天花板在哪里

- **不要按“爆款游戏”估值。** 它没有内购数值、没有养成付费点、没有多人实时玩法、没有账号体系，注定吃不到游戏行业的高 ARPU。
- **也不要按“工具”估值。** 它的核心是情绪和叙事，不是效率。工具可以靠功能留人，它只能靠内容和共鸣留人，内容生产速度就是它的产能上限。
- **合理的价值定位是：一个有文化辨识度的长尾叙事产品 + 一套可授权的生涯讨论工具。** 前者养名气和故事资产，后者养收入。这个组合的天花板是“小而稳、有口碑、可持续”，不是“规模化暴利”。

**独立判断：未来价值的中位数是“值得长期做的副业 / 小团队产品”，乐观情形是“成为中文人生分岔题材的代表作之一”，悲观情形是“叫好但不持续，因为内容生产速度跟不上玩家消耗速度”。三种情形的分水岭不是创意，而是上线后前 3 个月的数据和内容更新节奏。**

## 五、变现能力：C 端是小钱，B 端是大钱但慢钱，广告是最差选项

### 分项打分（5 分制，只代表相对潜力，不是收入预测）

| 变现路径 | 潜力 | 理由 |
|---|---|---|
| C 端珍藏付费（纪念、人生册、长图 / PDF） | ★★☆☆☆ | 情感付费，单价低、转化低。设计书自己测算：10 万玩家量级只有几十万日元量级。优点是不卡玩法、不破坏口碑，适合当“纪念品”，不适合当主收入。 |
| 主题内容包（毕业季、过年回家、女性重启、大龄转行等） | ★★★☆☆ | 比珍藏更可持续，因为新包就是回访理由。但每个包都要人工审核，生产成本高，且要先有用户才有人买包——是增长的结果，不是增长的原因。 |
| B 端授权与定制（学校生涯课、咨询、企业关怀、联名主题包） | ★★★★☆ | 真正的收入杠杆。学校和企业买的是“能引发讨论的工具 + 讨论提纲 + 聚合报告”，不是游戏本身。缺点是销售周期长、需要案例和数据背书、需要教师手册和合规材料，现在这些都还是“未实现”。 |
| 广告 | ★☆☆☆☆ | 不建议。设计书已判：看广告解锁破坏沉浸与口碑，广告收入还比珍藏低一个量级。不要为了小钱拆掉人文定位。 |
| 订阅 | ★☆☆☆☆ | 不适合。没有账号、没有持续服务、没有跨设备同步，硬做订阅只会让用户觉得“为本地单机游戏交月费”。除非未来做了账号 + 云存档 + 持续内容包，那时再谈。 |

### 变现顺序（独立判断，与设计书一致，但理由更苛刻）

1. **C 端先免费、完整可玩，珍藏只卖纪念。** 任何“付费改命、付费看影子全貌、付费解锁好结局”的设计都会直接摧毁立意和口碑，不要碰。
2. **C 端的任务不是赚钱，是攒三样东西：** 真实完局 / 分享数据、授权玩家故事、媒体可引用的案例。没有这三样，B 端销售没有弹药。
3. **B 端不要先做完整版，先做小样。** 一个学校 / 一个咨询场景的引导版小样（讨论提纲 + 教师手册 + 匿名聚合报告样例），拿去谈 3–5 家种子机构，比先把 B 端平台做全更划算。
4. **价格不要拍脑袋。** 增长文档提到的珍藏价格 A/B（如 ¥480 / ¥680 段）只是内部实验起点，上线后 4 周转化 <0.3% 就应停止优化 C 端付费投入，把主线切到 B 端——这条止损线比价格本身重要。

### 现金流提醒

- 成本结构是“前期内容人工成本高、后期分发边际成本近零”（纯静态 + CDN）。这意味着它扛得住流量，但扛不住“长期没人买单的内容生产”。
- 设计书提到的现金上限口径（¥100,000 量级纪律）如果仍然有效，就更应该把钱花在“上线 + 埋点 + 真机试玩”上，而不是提前做日文版、B 端平台或大规模内容包。

## 六、完整优缺点总表

### 优点（按对长期价值的贡献排序）

1. 题眼真、机制差异化真（影子人生）。
2. 确定性种子引擎 + 零在线 LLM：成本低、抗流量、可复现、可对战。
3. 状态矩阵与校验工具：长期内容扩容的地基，穿帮率可控。
4. 内容量过门槛：2150 个 ID，第二局重复率按模拟数字看是低的。
5. 分享台与同局链接骨架完整：卡型、尺寸、系统分享、复制文案都有了。
6. 伦理与隐私克制：不卖改命、不排名、不打卡焦虑、本地存档。
7. 纯静态部署：Cloudflare Pages + CDN，百万级访问前的分发成本接近零。
8. 留存设计克制但有心意：本地 streak / lastlife / 每日种子，不搞焦虑设计。

### 缺点（按对失败的贡献排序）

1. **未上线、无真实数据。** 所有增长与变现数字都是情景测算，不是验证。
2. **第一分钟不够锋利。** 5 条相似毕业路线，影子卖点要到 30 岁才瞥见，首屏体积偏大。
3. **裂变闭环未补齐。** 挑战横幅、对照卡、钩子 A/B、埋点、故事墙、短链 / 动态 OG 仍是缺口或待核对项。
4. **影子仍是查表文本。** 完整推演引擎未实现，核心卖点有“名不副实”的口碑风险。
5. **决策密度与策略深度低。** 8 个大分岔 + 数值无胜负，长期留存靠内容新鲜度，不是玩法深度。
6. **供给偏斜未同口径复测。** 关系 / 金钱形状坍缩、单身 / 无孩线薄、城市白领偏斜、年代错位、伴侣悬空等历史问题，修了机制不等于修了供给。
7. **内容生产是瓶颈。** 人工审核不可省，主题包、日文版、B 端版都要重写，一个人维护的产能上限就是产品的增长上限。
8. **本地存档的代价。** 换设备丢失、清缓存归零、无跨设备同步——免注册的优点，反过来就是留存与付费的短板。
9. **平台与合规未验证。** 微信生态外链限制、国内收款与内容合规、日文在地化成本、英文名商标风险，都还停留在“待验证”清单里。
10. **定位张力。** 人文克制主动放弃了梗、排名、收集奖励等最有效的短期杠杆；如果找不到“克制但可截图”的瞬间，分享卡可能好看但不好转发。

## 七、改进方案建议（按优先级，不按功能清单）

### P0：上线验证（先做这 4 周，其他都往后放）

1. **把站点真正上线。** 按 `docs/DEPLOY-CLOUDFLARE.md` 完成 Cloudflare Pages 接入，推 `main` 自动部署，确认 `if-that-year.pages.dev` 可访问、OG 图与描述在各平台预览无缺图。
2. **上匿名埋点，而且只上 P0 事件。** 开局、完局、影子点击、分享台打开、有效分享（系统分享 / 复制文案 / 保存图片）、同局链接落地与开局、每日种子开局。没有埋点，后面所有判断都是猜。
3. **首屏瘦身。** 事件包按年代懒加载，目标首屏 <200KB（竞品报告建议值）；先测 390×844 手机弱网下的首屏与第一张事件卡到达时间。
4. **20–30 人真机试玩 + 复盘。** 不要只看问卷，要看录屏 / 路径：多少人 3 分钟内触达影子概念？多少人中途退出？退出点在第几岁？试玩结论直接决定 P1 做什么。

**止损线（沿用增长文档，独立判断同样认可）：** 完局率 <40% 且改一版仍不升 → 停 C 端扩张，转 B 端课堂工具小样或止损；分享率 4 周 <8% → 裂变不成立，不买量；珍藏转化 4 周 <0.3% → 停止优化 C 端付费，主线切 B 端。

### P1：让第一分钟成立（上线数据出来后再做，不要提前堆）

1. **影子瞥视前移。** 在 25 岁分岔之后就给一次“影子 teaser”（只给标题 / 一行剪影，点开才看全文），让核心卖点在开局 3 分钟内出现，而不是等到 30 岁。
2. **轻局模式独立成档。** 22–45 岁、10–15 分钟、结算同样完整；完整局（到 80 岁）保留给愿意深读的玩家。轻局是裂变的主力，完整局是口碑的压舱石，两者不要混成一个“可长可短”的模糊模式。
3. **一句话钩子 A/B。** 候选：“你的另一条路，过得比你好吗？” / “30 岁那年，你敢看吗？”放在 OG 标题与首屏，按种子尾号分组，观测 2 周或每组 ≥300 次有效分享，先到为准。只涨分享不涨开局的版本算输。
4. **开局差异再推一格，但不改路线脊柱。** 出身牌已经做了三类牌各 3 选 1，接下来要验证的是：玩家是否感知到了差异？如果试玩反馈还是“5 条路差不多”，优先加“路线专属事件密度”，而不是再加路线数量。

### P2：把裂变闭环补齐（按断点顺序，不要一次全做）

1. 挑战落地横幅：链接带挑战摘要（分享者判词一句 + 关键分岔一句），落地页首屏明示，点主按钮 1 次直达同种子选路。
2. 同局对照卡：挑战链接完局后，结算页自动出“分享者判词 vs 本人判词”对照块，并可生成对照卡——这是第二轮传播的本体。
3. 卡面钩子 A/B：同命对照型 vs 影子悬念型，按 §P1 的方法跑满再判。
4. 静态故事墙：≤12 条经授权的真实分岔故事，纯静态、无评论、无点赞数，首页只放 3 张入口。每条必须有授权记录编号，投稿与发布双重同意分开勾选，可撤回。
5. 短链与动态 OG：等指标证明 Loop C 值得投入再做，之前只用静态 OG 图 + 一句钩子描述，不假装个性化。

### P3：内容质量审计（字段活优先于重写）

1. **用三方审稿的同口径重跑一遍：** 门控缺失率、判词形状分布（关系登顶 / 金钱垫底是否还坍缩）、年代错位条数、伴侣 / 孩子悬空率、变体互斥（猫死两次类问题是否复发）。
2. **补薄格子，不追总量。** 优先补：单身线、无孩线、县城 / 农村线、蓝领 / 个体经商线、35–55 岁“算账文体塌陷带”、65 岁后之外的中年日常。总量从 2150 再往上加，边际收益已经很低。
3. **在 5%–10% 的平年微文本里留小幽默位置。** 不涉政、不玄幻、不嘲讽活法，只留自嘲式的小笑点——目的是给玩家一句“可以笑着截图的话”，不是把产品改成搞笑游戏。
4. **判词池加厚，但不改规则。** 格言腔的早期片段（约 8 条被点名）先改写；判词形状不变，文本变体先加，撞句率目标仍按 <5% 完全相同来验收。
5. **把“数字有出处”变成卖点。** 结算页加一行“本局参照：……（出处）”，把克制变成可信度；查不到出处的数字一律降级为定性描述，这条红线不要为传播效果放宽。

### P4：变现测试（C 端小步，B 端小样，两条线并行但预算分开）

1. C 端：珍藏（人生册 / 长图 / PDF）小范围上线，价格 A/B，验收只看 4 周转化与用户原话，不看“卖了多少张”这个绝对数。
2. B 端：先做 1 个引导版小样（讨论提纲 + 教师手册 + 匿名聚合报告样例），谈 3–5 家种子机构；同时把求助资源（中 / 日）逐条核实、定期复核的流程写进文档——这是 B 端采购的硬门槛。
3. 日文版：不要全量翻译先行。先做“在日华人”种子圈的小范围试点，验证在地生活成本数据（房租、育儿、正社员 / 派遣）与文化事件是否成立，再决定全量日文版投入。
4. 明确不做的变现：看广告解锁、付费改命 / 好结局、订阅（无账号前提下）、实时 UGC 流与点赞排行。

### P5：如果验证失败， pivot 方案（提前写好，免得到时恋战）

- **转 B 端课堂工具：** 砍掉裂变与珍藏，保留引擎 + 状态矩阵 + 讨论提纲，做成教师可用的“人生分岔讨论课”小样。
- **转叙事模板 / 内容授权：** 把事件库结构、状态矩阵、判词生成规则做成可授权的模板，卖给播客、出版社、公益机构做联名主题包。
- **转个人作品 / 展览：** 接受它是一个文化产品而非商业产品，把故事墙和精选人生做成展览 / 出版素材，收入目标从“规模化”降为“覆盖成本 + 口碑”。

## 八、给作者的三句直话

1. **你最强的不是“写了很多事件”，而是“给选择建了一套不会穿帮的规则”。** 状态矩阵、注册表、校验工具、确定性种子，这些才是后来者最难抄的东西——要继续把它当成护城河来维护，不要为了赶内容量放宽入库门。
2. **你最危险的不是“没人玩”，而是“第一批人玩完后觉得‘还行，但没必要转发’”。** 温暖、克制、体面，这些词在试玩反馈里是优点，在传播漏斗里是风险。P1 的影子前移和轻局，就是为了解决“还行”这个问题。
3. **不要用“我再写 500 条事件”来回答所有问题。** 现在的问题清单里，排在前面的都是链路、钩子、埋点、复测、合规这些“不是写事件”的事。内容量已经够了，下一步的瓶颈在产品，不在文案。
