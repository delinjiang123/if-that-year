# 如果那年

> 你没走的那条路，过得怎么样？

选一个年代，从小时候活到老。你没选的那条路，也会自己走完，你会时不时看见它过得怎么样。

**线上**：https://if-that-year.sommeatlas.com （当前 v0.60.147）

**本地**：纯静态、免构建、免注册，任意静态服务器打开即可：

```bash
python3 -m http.server 8000
# http://localhost:8000  （带种子: http://localhost:8000/?seed=434）
```

## 玩什么

- **年代与出生年。** 六个年代，从 1950 年代到 2000 年代。出生年可以在十年里任选一年，也可以不选、交给随机；大事件绑公历年份，不绑年龄——同一件事，不同年代、不同年纪的人遇上，样子不一样。
- **一生的走法。** 上学、工作、成家、父母老去、退休之后再过一程。岔路跟着事件和处境走，不在某个固定年龄等你；走错一步也不会把一生走死，每个年纪都有回头的路。
- **职业。** 入行靠从小到大的选择一点点攒，攒下的伏笔到关口会回头点名；也允许半路冷进一个毫无铺垫的行当，转行一直开着，不是入一行干一辈子。目前 19 条职业线已经整线闭环——入行、站稳、转行、晚年六段齐全，包括工厂、小店、种地、手艺、教书、报社、医护、写作、林业、会计、金融、程序员、快递外卖、照护、司机、矿工、考公、建筑、摄影。出海打渔、出国劳务也各有整段的日子。
- **影子。** 没选的那条路会按它自己的性子把一生走完。平时只在几个年纪远远瞥见一眼，结算时才看全貌；它过得是另一种日子，不跟你比高下。
- **父母。** 父母的寿命按他们自己的年纪算——他们是已经把孩子养大的人，不按主角的年纪倒推。回去陪、陪着看病、搬近住、操办寿宴，这些照护的选择不只是加好感，是实实在在给父母多添几年。父母活到八九十岁、主角六十岁时一家人还齐整，是这游戏里常见的画面。
- **钱。** 大多数人过完一生是够用、有点富余。富贵也有，但概率低：长年头守一行、又做成过事的人，结算时钱槽之上还有一档「富贵」；靠的不是纯运气。纯外财只有拆迁一条口，概率压得很低；彩票保留着，概率极低，只算日子里的一点念想。
- **出国。** 留学、在地就业、换身份、拿永住、买房安家，一整条链已经走通；回程也有正脸（读不下去回来、海归落地），不是出了国就回不了头。
- **结算。** 判词、年表、分岔长图，全部只读这一生的账本拼装：发生过什么写什么，没发生的一个字不编。手写特殊结局 33 个，只是最上面一层；普通结局由这一生的职业、家庭、住处、关系与晚年组合而成，每一局都不一样。内容量：全库 5,838 条、台账 6,039 条（计数见 docs/DEVLOG.md 的 v0.60.120 条目）。

## 本质

这是一个关于「另一条路」的游戏。它的全部设计只为撑住一件事：玩家活完一生之后，能回头看见当年没走的那条路过得怎么样——不是一句感慨，是另一段被完整活过的人生。

几条立场，定了就不再动：

- **出身靠发，选择靠人。** 年代由玩家选，出生年任选或交给随机，家庭与出身由种子抽定，没有重抽。玩家能定的只有后来的路，人生的不甘心正从这里来。
- **两条命，一本账。** 主角和影子是同一套规则跑出来的两段完整人生，共享同一个出身。影子不是陪衬文案，它真的活了一遍。
- **事实先于文案。** 一生发生过什么，先记进账本；结算、判词、典藏都只读账本拼装。没发生过的事，一个字不许编。
- **结局不分高下。** 没有最优人生，没有完成度和稀有度档位。分岔图上未选的路只是淡去，不排座次。
- **对局零 AI。** 玩法与结算全部由规则和种子决定，同一开局永远走出同一段人生。AI 只在生产侧帮忙写稿查错，进库的文案都过人手。

## 架构

**确定性种子引擎。** 整个游戏是一台可复现的机器：主、世界、环境、序章、判词各走独立随机流，互不扰动。同一游戏版本、同一设置与同一种子，同一段人生——对局可分享、可对战、可审计，任何一局的任何一年都能重放出来对账。（跨版本不承诺同一局：分享链接带内核版本位，旧链接打开同一种子按新口径走，策略见 DEVLOG v0.18.0 条目。）

**状态机，不是标记堆。** 配偶、子女、父母、宠物等人生状态是带类型的状态机：流转只能走注册表声明的边，门控查当前状态。去世的状态没有出边，数据层就写不出「父亲复活」。注册表（`src/registry.js`）是单一事实源，内容入库前过校验器，未登记的引用、不可逆的违规在门口报错。

**内容即数据，叙事从状态里长出来。** 全库事件是带门控条件的数据（storylet），调度器按这一生的当前状态挑选与呈现，不存在手写的主线分支树。岔路跟着事件和处境走，不跟固定年龄走；一个选择的影响靠后文事件读状态回响，而不是当场结算分数。

**影子是一台同规的第二模拟。** 影子在第一次大岔路从主角的出身分出，用自己的随机流、按自己的性子政策把一生走完。呈现层只给瞥见：几个年龄点远远看一眼，结算才揭晓全貌。呈现是模拟的只读投影，改呈现不能改命。

**结算只读。** 结算页、判词、分岔长图与付费典藏都是账本的纯派生：输入是这一生的事实记录，输出是排版。同一记录永远拼出同一份结算。

**纯静态。** 无构建、无服务端状态，存档在本机。仅有的动态端点是匿名埋点收集与典藏兑换。扩容靠静态本身，见 [docs/SCALING.md](docs/SCALING.md)。

**验证是开发的一部分。** 断言守住关键机制，普查给出分布数字；任何写进文档的数字都必须有一次真实运行作出处，查不到就降级为定性描述。

## 结构

```
index.html          入口（静态直出，Cloudflare Pages）
src/engine.js       引擎主体（随机流 / 状态 / 调度接线 / 结算 / 分享）
src/registry.js     状态注册表（域、流转边、旗标的单一事实源）
src/scheduler.js    调度器（按状态挑事件，呈现与「差一步」解释同读一个判定本体）
src/record.js       账本（这一生的事实记录，结算的唯一输入）
src/content/        内容数据（通用池 / 链路线 / 年代包 / 稀有 / 序章与出身）
src/world/          世界进程（父母、健康与死亡、影子人生）
functions/          动态端点（埋点收集、典藏兑换）
tools/              校验器与断言（内容与机制的入库门）
docs/               设计书、开发日志与各专题文档
```
